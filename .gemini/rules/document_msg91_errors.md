# MSG91 Architecture Documentation Rule

**Context:** The `docs/MSG91_ARCHITECTURE_AND_DEPLOYMENT.md` file serves as the strict source of truth for the project's inbound/outbound systems and troubleshooting.

**Rule:** 
Whenever you encounter and fix an unexpected or expected error in the application's functioning, you **MUST** immediately document the error in `docs/MSG91_ARCHITECTURE_AND_DEPLOYMENT.md`. 
Include the following:
1. The symptoms of the error.
2. The root cause.
3. The exact solution implemented.
